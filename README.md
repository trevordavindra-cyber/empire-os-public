# EMPIRE OS

Built files of the Lovable app "EMPIRE OS - Autonomous AI Business Organization", pulled from the live published site https://image-match-garden.lovable.app on 2026-11-04.

- The full build is unzipped in this repo: `index.html` plus `assets/`. Every file is readable here directly.
- To run it: download the folder and serve it with any static file server (`python3 -m http.server`), then open http://localhost:8000. A double-click on index.html will not work because the scripts are modules.
- This is the compiled build, not the editable Lovable source. No backend or API is wired in. The editable source lives only in the Lovable editor, project id `lovp_1hzfwn3mg38p9aqd81ese502aq`.
